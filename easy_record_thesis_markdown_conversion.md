# Introduction

## Project Overview

In **“Easy-Record”**, we are trying to implement an Audio Recording Application.

“Easy-Record” is a Mobile Application which allows users to Record Audio in Raw data in PCM.

My-Shop is a mobile app through which you can record audio anytime and it’s very user-friendly. Being a mobile Application, it allows users to access the facility anywhere anytime.

In today's time, all the audio recording app is only providing audio record feature but if user want to save details about who is doing recording with whom. So, for that we have develop this application in that you can save user details with images.

You can record audio in multiple formats with this application. We will provide on dropdown to select different type of format to do recording. And we also give option for sampling rate so user can customize the recording settings based upon their requirements of audio. “Easy-Record” has one phases user phase.

---

## User Phase

In User phase user can login our self by filling mobile number. After filling we will provide them 6-digit OTP. After successfully verification of OTP user can login to the app.

In the home screen user can see list of recorded audios. Or if he wants to create new recording then he can click on Create Recording button so he can create recording.

When user fill his details and select images, he can go to record audio and after recording audio he can play recorded audio in the Preview screen. After doing success full recording user can navigate to home screen and he can see the details about recorded audio.

# Feasibility Report

Preliminary investigation examines project feasibility, the likelihood the system will be useful to the organization. The main objective of the feasibility study is to test the Technical, Operational and Economical feasibility for “Easy-Record” adding new modules and debugging old running system. All system is feasible if they are unlimited resources and infinite time.

The aspects in the feasibility study are:

- Technical Feasibility
- Operational Feasibility
- Economic Feasibility

## 2.1 Technical Feasibility

The technical issue usually raised during the feasibility stage includes:

- Does the necessary technology exist to do what is suggested?
- Can the system be upgraded if developed?
- Are there technical guarantees of accuracy, reliability, ease of access and data security?

The current system developed is technically feasible and provides easy access to users with a reliable database structure.

## 2.2 Operational Feasibility

Operational feasibility aspects of the project are to be taken as an important part of the project implementation.

- Is there sufficient support for “Easy-Record” from the users?
- Will the system be used and work properly if it is being developed and implemented?

## 2.3 Economic Feasibility

A system can be developed technically and that will be used if installed must still be a good investment for “Easy-Record” for the organization.
